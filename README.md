# java-racingcar-precourse

## 기능 요구사항

* 쉼표(,)로 구분된 자동차 이름을 입력받는다.

* 자동차 이름은 1~5자 이내이며, 빈값 및 공백을 포함할 수 없다.

* 사용자는 전진 시도 횟수를 입력할 수 있다.(정수)

* 매 시도마다 자동차별로 0~9 사이 난수를 구하고, 4 이상이면 전진한다.

* 각 시도(라운드)가 끝나면 자동차의 이름과 위치를 출력한다.

* 모든 시도 종료 후, **최종 우승자(최대 위치)**를 출력한다.

* 우승자가 여러 명이면 쉼표(, )로 구분한다.

* 잘못된 입력 시 IllegalArgumentException을 발생시키고 프로그램을 종료한다.

## 요구 기능 정리(실행 흐름)

# 입력

* 경주할 자동차 이름 입력 (쉼표로 구분)

* 전진 시도 횟수 입력

# 검증 (예외 처리)

* 잘못된 입력 시 IllegalArgumentException 발생 후 프로그램 종료

- 검증 항목	내용
- 이름 길이	5자 초과 여부
- 이름 유효성	빈 값 또는 공백 포함 여부 (예: pobi,,jun)
- 이름 중복	중복된 이름 존재 여부 (예: pobi,pobi)
- 횟수 유효성	숫자가 아닌 값 입력 여부 (예: five)
- 횟수 범위	0 이하의 숫자 입력 여부

# 핵심 로직

* 입력받은 이름 문자열을 Car 객체 리스트로 변환

* 시도 횟수만큼 라운드 반복 (for문)

* 각 자동차별로 0~9 난수 생성

* 난수가 4 이상일 경우 해당 자동차의 position 증가 (3 이하면 정지)

* 모든 라운드 종료 후 position이 가장 큰 자동차를 우승자로 선정 (공동 우승 가능)


# 출력

* "실행 결과" 헤더 출력

* 매 라운드 종료 시, 자동차 이름과 전진 상태 출력
  
- 예:
- pobi : --
- jun : -


* 모든 라운드 종료 후, 최종 우승자 출력

- 예:
- 최종 우승자 : pobi, jun
